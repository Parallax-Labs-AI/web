⚡ LOAD MODEL — REQUIRED

You must download a GGUF model file before chatting.

1. Visit the official model repository:

https://huggingface.co/parallaxlabs/parallax-2-preview

2. Download the Q4_K_M GGUF file (e.g. parallax-2-preview-Q4_K_M.gguf).

3. Open Settings → Choose File and select the downloaded .gguf file.

ⓘ You only need to do this once. After loading, you can start chatting immediately — everything runs locally in your browser.
