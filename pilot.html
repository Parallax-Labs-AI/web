Parallax Pilot

Parallax Pilot is a local AI agent that can start work before you send a prompt. Run multiple Pilot teammates so they can message each other, share findings, and work on different parts of a project in parallel. You can message any teammate directly to ask for an update or change its priorities.

What Pilot teammates can do

Get started on their own

Pilot can take the first step on work in your workspace before you send a chat message.

Work together

Teammates can message each other, divide tasks, and hand off work. One can make a change while another writes tests.

Hear from you directly

Message a specific teammate to ask what it’s doing, share context, or steer the work already in progress.

Read across a codebase

Parallax Mini models give Pilot up to 1 million tokens of context for working across files in a project.

Use workspace tools

Teammates can read and edit files, run commands, and use web search when a task calls for it.

Run on your hardware

Pilot runs inference locally using Parallax models.
