Pilot, powered by Parallax 2 Mini, uses Gated DeltaNet architecture. This means that Pilot can run significantly more efficient than standard Transformer models. It can run its full 1 million context on approximately 5GB of VRAM.

Pilot doesn't just provide an answer, it can take action, such as create or edit files, create folders, run commands, search the web, and more tasks with the Parallax App API.

Pilot is designed for local on-device inference, meaning your data is safe with Pilot, and never leaves your device.
